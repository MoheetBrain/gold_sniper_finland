# Synthetic example — not Finnish measurements

Generated by `python scripts/demo.py --output data/example` with seed 42 and 500 Monte Carlo iterations. All cell identifiers begin with `synthetic_`; coordinates refer to a fictional metric plane. Do not map them onto Finland.

| File | Meaning |
|---|---|
| `synthetic_features.csv` | 900 invented cells, geometry-derived distances/counts, artificial gravity-like field, sparse synthetic chemistry, roles, blocks and overlap percentage |
| `synthetic_oof.csv` | Evaluated subset with binary synthetic labels and held-out model scores |
| `folds.json` | Train/test indices, block membership, training medians and class weights |
| `summary.json` | Synthetic metrics, ablations and 200 random-baseline draws; not real-data performance |
| `synthetic_mc_inputs.csv` | Declared 16-cell synthetic candidate pool |
| `synthetic_mc.csv` | Conditional rank frequencies, score mean/SD and group scores; no calibrated probability |

Distances are metres, `area_km2` is square kilometres, `taken_overlap_pct` is percent. `gravity_gradient` is a unitless artificial feature here (unlike historical mGal/km). `till_au_clr` is generated noise with missing values, not an assay or true compositional CLR. `role` is positive/background/buffer_excluded. `model_score` is a weighted-classifier score, not a calibrated probability. `top_5_freq` concerns five **cells**, not five percent.

Source code and synthetic data are project-authored; proposed licensing is subject to the publication gate. No third-party observations are incorporated.
